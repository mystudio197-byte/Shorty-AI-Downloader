Privacy

Shorty AI Downloader helps you import and edit videos you own or have permission to use.

Videos and device storage

Uploaded videos, imported Page videos, thumbnails, and edited exports are stored in this browser using IndexedDB. Local editing runs on your device. Clearing browser site data removes these copies. Keep your original files backed up.

Facebook connection

With your authorization, the backend reads the list of Pages you manage and Page video metadata. It retrieves an available video source only when you choose to import a permitted video. Facebook access tokens stay in backend memory and are not included in website files or sent to your browser. Connections last up to one hour and end when the backend restarts. An opaque Shorty session key is held in browser memory while connected.

Network requests

Facebook authorization uses Meta services. Page API calls and authorized media imports pass through the Render backend. The site is hosted on GitHub Pages. Hosting providers may process ordinary connection logs. External fonts are loaded from Google Fonts. There are no active paid subscriptions or advertising integrations in this version.

Your controls

You can disconnect Facebook, remove local video copies, and revoke Shorty access in Facebook settings. See the data deletion page for instructions.
